How I work

Measure, never recall

Every number I report is the output of a command run at the time, labelled as measured, published or a target.

Hold AI output to evidence in code

A model proposes; code verifies every quote against the raw output; a person approves anything irreversible.

Score AI against answers written in advance

Answer keys come first, built from real cases, with "no fault" cases so the system cannot win by agreeing.

Calibrate, then guarantee

Confidence is recalibrated on labelled data and accepted only with a stated error bound; uncertainty spends money, never accuracy.

Production is the test bench

Every build is walked from an empty folder; the collector was hardened by ten real estate runs in three days.

Plans and gates

Every phase opens with a written plan approved before code, and every release waits at a human gate.
